# Rule-Based Chatbot 🤖

## 📌 Overview
This is a simple rule-based chatbot developed using Python as part of my Python Programming Internship at CodeAlpha. The chatbot responds to predefined user inputs through basic conditional logic.

## 🎯 Features
- Responds to user inputs like:
  - hello
  - how are you
  - help
  - bye
- Continuous interaction until exit
- Beginner-friendly and easy to understand

## 🛠️ Technologies Used
- Python

## 🧠 Concepts Used
- Functions
- Loops
- Conditional statements
- Dictionaries
- Input and Output
